Week 03: Investigation of the Barbell results and statistical test

Overview

Barbell issue, outliers and sequencing kits

  • I didn’t see any critical data loss in the barbell-processed datasets when looking at the initial depth and/or file size. However, barbell seems to struggle to process certain samples for specific metrics.

  • Yes, we do have outliers, but the outliers differ across metrics we tested. Some of comboinations did better job handle them and others did a poorer job. Other than that, the outliers dragged down the performance metrics across all combos.

  • Rapid generally produce better result in assemblye errors, but worse result in NGA50. For other metrics, the sequencing kits don’t show much difference in the results.

Statistic metric we use

  • Because we want to assess the impact of preprocessing against the raw (unprocessed-untrimmed) data, and because our metrics are not normally distributed, I used the non-parametric Wilcoxon test where we rank the point to evaluate the differences for the same sample across different treatments compare against the raw. Also, because we ran these tests multiple times across samples, models, and downsampling depths, I applied a False Discovery Rate (FDR) correction for multiple testing. The result now, we found no significant differences for F1 scores for variant calling and mismatches for genome assembly, but we did find a few significant differences for indel metrics in genome assembly.

  • Because the non normal (skewed) distribution, i think we better to use median to represent the data. That said though, we might lose some signal from the combinations, as certain combinations perform better when processing specific samples (such as outliers) but don’t show much difference on other samples compared to the rest of the combinations.
