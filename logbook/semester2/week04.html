auNGA and auNGA ratio

auN or auNGA is the area under the Nx or NGAx curve. It summarises the assembly contiguity with a single number. It is a better choice than Nx or NGAx as it is more stable, less affected by big jumps in contig lengths, and considers the entire Nx or NGAx curve. It was proposed and justified by Heng Li in his blog.

It is calculated by dividing the sum of squared contig lengths by the sum of contig lengths (or assembly span):

\[\text{auNGA} = \sum_i A_i \cdot \frac{A_i}{G} = \frac{\sum_i A_i^{2}}{G}\]

The auNGA ratio is then calculated by dividing the auNGA value by the auN from the reference:

\[\text{auNGA\ ratio} = \frac{\mathrm{auNGA}}{\mathrm{auN}_{\mathrm{ref}}} = \frac{\sum_i A_i^{2}}{\sum_j R_j^{2}}\]

Plotting the auNGA ratio

The ideal auNGA ratio is 1. Mathematically, the value can exceed 1, which indicates high duplication. To plot it on a logit scale and bound the value between 0 and 1, we normalise the auNGA ratio by calculating its distance from 1:

\[\text{Score} = \max(0, 1 - |x - 1|) \times 100\]

High sequences errors from Barbell assemblies

Taking a closer look at the specific sample BPH2947__202310 filtlong-barbell processed (SUP 20x), we can see that both sequence errors (mismatches and indels) are indeed clustered in certain positions along the genome.

I did not use paftools.js from minimap2 misc. Instead, QUAST also provides a raw SNP report that contains information about the error bases, reference bases, and the genomic coordinates. I binned these to 100kb and produced the error density plot below:

Actually, the error profile is different in other barbell processed assembly

I mapped the filtlong-barbell reads, which had the high 7.8 mismatches/100kbp rate, back to the reference genome. When I zoomed into the ~0.45 Mb region, I found it had little to no read coverage. In contrast, the dataset with the lower mismatch rate covers this region well. Does this definitively prove that Barbell is causing the issue? Or is it due to the downsampling step, given that the 100x depth did not struggle with it, but actua; it is a problem at 50x as well. So i think the issue is in the barbell overtrimming. Alternatively, does this indicate that the assembler doesn’t actually need very high depth as long as the region is covered well?

The adapter trimmer, in this case Barbell, was overtrimming or performing overaggressive trimming in this region, causing a severe drop in coverage.

from pathlib import Path
import matplotlib.pyplot as plt
from matplotlib.lines import Line2D
import pandas as pd
import seaborn as sns
from typing import List

# --- Configuration ---
# Set your input CSV and output directory here
input_csv = "../../results/tables/assess/call-100x-20x/metrics/combo_variant_summary.csv"
out_dir = Path("../../../../../qc_bench_manuscript/figures/")
out_dir.mkdir(parents=True, exist_ok=True)

# Colourblind-friendly palette from colour universal design (CUD)
named_colors = {
    "black": "#000000",
    "orange": "#e69f00",
    "skyblue": "#56b4e9",
    "vermilion": "#d55e00",
    "bluish green": "#009e73",
    "yellow": "#f0e442",
    "blue": "#0072b2",
    "reddish purple": "#cc79a7",
}
cud_palette = list(named_colors.values())

def cud(n: int = len(cud_palette), start: int = 0) -> List[str]:
    remainder = cud_palette[:start]
    palette = cud_palette[start:] + remainder
    return palette[:n]

sns.set_theme(style="whitegrid")

# --- Load Data ---
print(f"Loading data from {input_csv}...")
df = pd.read_csv(input_csv)

# Filter out 'ALL' and 'SV'
data = df.query("VAR_TYPE not in ('ALL', 'SV')").copy()

# Deduplicate to keep the best F1 score per sample/combo/model/depth
dataix = data.groupby(["combo", "depth", "VAR_TYPE", "sample", "model"])["F1_SCORE"].idxmax()
data = data.loc[dataix].copy()


# --- PRE-CALCULATE OUTLIERS FOR PLOTTING ---
print("Calculating outliers for plot annotations...")
q1 = data.groupby(["combo", "depth", "model", "VAR_TYPE"])["F1_SCORE"].transform(lambda x: x.quantile(0.25))
q3 = data.groupby(["combo", "depth", "model", "VAR_TYPE"])["F1_SCORE"].transform(lambda x: x.quantile(0.75))
iqr = q3 - q1
lower_bound = q1 - 1.5 * iqr

# Create a boolean column tagging if a row is an outlier
data['is_outlier'] = data["F1_SCORE"] < lower_bound

# Identify the top 4 most frequent outlier samples
outlier_counts = data[data['is_outlier']]['sample'].value_counts()
top_4_samples = outlier_counts.nlargest(4).index.tolist()

# Map samples to their categories (Top 4 names, or 'Other')
data['outlier_category'] = data['sample'].apply(lambda x: x if x in top_4_samples else 'Other')
outlier_categories = top_4_samples + ['Other']

markers = ['^', 'D', 'X', 's', 'o',]

# Save the outlier CSV
all_outliers = data[data['is_outlier']].copy().sort_values(by="F1_SCORE")
outlier_csv_path = out_dir / "all_outliers.csv"
all_outliers.to_csv(outlier_csv_path, index=False)
print(f"Full outlier details saved to {outlier_csv_path}")


# --- Plotting Variables ---
metrics = ["F1_SCORE", "PREC", "RECALL"]
vartypes = ["SNP", "INDEL"]
models = ["sup", "hac"]
estimators = ["mean", "median"]
plot_types = ["point", "box"] # Changed 'strip' to 'box' here
hue_order = ["100x", "20x"]

# --- Generate Plots ---
print("Generating plots...")
for y in metrics:
    for est in estimators:

        if est == "mean":
            combo_perf = data.groupby("combo")[y].mean()
            est_func = 'mean'
        else:
            combo_perf = data.groupby("combo")[y].median()
            est_func = 'median'

        order = combo_perf.sort_values(ascending=False).index.tolist()

        for p_type in plot_types:
            fig, axes = plt.subplots(
                nrows=len(vartypes),
                ncols=len(models),
                figsize=(24, 12), # Increased width and height for clarity
                dpi=300,
                sharex=True,
                sharey=False,
            )

            for r, vartype in enumerate(vartypes):
                for c, model in enumerate(models):
                    ax = axes[r, c]
                    df_plot = data.query("VAR_TYPE == @vartype and model == @model").copy()

                    cap = 0.99999
                    df_plot.loc[:, y] = df_plot[y].apply(lambda v: cap if v > cap else v)
                    yticks = [0.01, 0.1, 0.5, 0.8, 0.9, 0.99, 0.999, 0.9999, cap]
                    yticklabels = [f"{yval:.2%}" for yval in yticks]

                    if not df_plot.empty:
                        if p_type == "point":
                            sns.pointplot(
                                data=df_plot, x="combo", y=y, hue="depth",
                                order=order, hue_order=hue_order,
                                palette=cud(len(hue_order), start=2),
                                ax=ax, dodge=0.3, errorbar=("pi", 100),
                                capsize=0.1, err_kws={"linewidth": 1.5},
                                estimator=est_func
                            )
                        elif p_type == "box":
                            # 1. Base Boxplot (No fliers)
                            sns.boxplot(
                                data=df_plot, x="combo", y=y, hue="depth",
                                order=order, hue_order=hue_order,
                                palette=cud(len(hue_order), start=2),
                                ax=ax, fliersize=0, gap=0.1
                            )

                            # 2. Overlay Outliers with Specific Shapes
                            df_outliers = df_plot[df_plot['is_outlier']]

                            for idx, cat in enumerate(outlier_categories):
                                cat_outliers = df_outliers[df_outliers['outlier_category'] == cat]
                                if not cat_outliers.empty:
                                    sns.stripplot(
                                        data=cat_outliers, x="combo", y=y, hue="depth",
                                        order=order, hue_order=hue_order,
                                        palette=cud(len(hue_order), start=2),
                                        ax=ax, dodge=True, jitter=0.1, alpha=0.85,
                                        marker=markers[idx], linewidth=0.8, edgecolor="black", size=5
                                    )

                    # Axis formatting
                    ax.set_yscale("logit", nonpositive="clip")
                    ax.set_yticks(yticks)
                    ax.set_yticklabels(yticklabels)

                    ylabel = {"F1_SCORE": "F1 score", "PREC": "Precision", "RECALL": "Recall"}[y]

                    if c == 0:
                        ax.set_ylabel(f"{vartype} {ylabel}", fontsize=13)
                    else:
                        ax.set_ylabel("")

                    if r == 0:
                        ax.set_title(f"{model} model", fontsize=14)
                    else:
                        ax.set_title("")

                    ax.set_xlabel("")
                    ax.set_xticks(range(len(order)))
                    ax.set_xticklabels(order, rotation=45, ha="right", rotation_mode="anchor", fontsize=13)
                    ax.xaxis.grid(True, linestyle='--', color='lightgrey', zorder=0)

                    # Custom Dual Legend Handling on top-right plot
                    if r == 0 and c == 1:
                        # Clear existing overlapping legends created by boxplot/stripplot
                        if ax.get_legend() is not None:
                            ax.get_legend().remove()

                        if p_type == "box":
                            # Color Legend (Depth)
                            color_palette = cud(len(hue_order), start=2)
                            depth_handles = [Line2D([0], [0], color=color_palette[i], lw=4, label=hue_order[i]) for i in range(len(hue_order))]
                            leg1 = ax.legend(handles=depth_handles, title="Depth", bbox_to_anchor=(1.02, 1), loc='upper left')
                            ax.add_artist(leg1) # Keep the first legend active

                            # Shape Legend (Samples)
                            shape_handles = [Line2D([0], [0], marker=markers[i], color='w', markerfacecolor='gray', markeredgecolor='black', markersize=8, label=outlier_categories[i]) for i in range(len(outlier_categories))]
                            ax.legend(handles=shape_handles, title="Outlier Samples", bbox_to_anchor=(1.02, 0.75), loc='upper left')
                        else:
                            ax.legend(title="Depth", bbox_to_anchor=(1.02, 1), loc='upper left')
                    else:
                        if ax.get_legend() is not None:
                            ax.get_legend().remove()

            fig.tight_layout()
            metric_file = "f1" if y == "F1_SCORE" else "precision" if y == "PREC" else "recall"
            new_output_path = out_dir / f"combo_variant_{metric_file}_{est}_{p_type}plot.png"
            fig.savefig(new_output_path, bbox_inches='tight')
            plt.close(fig)

print(f"Plots saved to {out_dir}/")

Both type of errors are usually localised or clustered in certain region in the genome, and these errors are usually at the of the contigs from the resulted assembly, that point to note that barbell pipeline also produce low contiguty produced more fragmented assemblies. Mapping the reads to the reference genome shows that the region were partly or only covered by very few of reads. Other things is, these high error rates are coming from native processed samples.
